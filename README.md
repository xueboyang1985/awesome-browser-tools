# Awesome Browser Tools [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of browser-based tools that process data locally — no upload, no server, no signup required.

**What qualifies:** Tools that run entirely in the browser. Your files and data never leave your device. Single HTML files or static sites. No backend, no accounts, no tracking.

## PDF Tools

- [PDF Tools](https://xueboyang1985.github.io/pdf-tools/) — Merge, split, convert, extract. 7 tools in one. Uses pdf-lib + jsPDF + pdf.js. Free up to 10 pages, PRO lifetime $9.99.
- [QuickTools PDF](https://github.com/QuickPDF/QuickTools) — Open-source PDF utilities. Merge, split, compress.
- [Stirling PDF](https://github.com/Stirling-Tools/Stirling-PDF) — Self-hosted PDF manipulation suite (requires local server). 50+ operations.

## Image Tools

- [AI Background Remover](https://xueboyang1985.github.io/background-remover/) — Remove image backgrounds with AI. ONNX neural network in WebAssembly. Free 720p, PRO HD+.
- [Image Compressor](https://xueboyang1985.github.io/image-compressor/) — Compress JPG/PNG/WebP via Canvas API. Adjustable quality. Free 5MB, PRO unlimited.
- [Image Resizer](https://xueboyang1985.github.io/image-resizer/) — Resize by pixels, percentage, or max dimension. Aspect ratio lock.
- [Image Cropper](https://xueboyang1985.github.io/image-cropper/) — Interactive crop with aspect ratio presets. Touch-friendly.
- [Squoosh](https://squoosh.app/) — Google's image compression tool. Side-by-side comparison. Open source.
- [Photopea](https://www.photopea.com/) — Full Photoshop-compatible image editor in the browser. PSD, Sketch, XD support.
- [SVGOMG](https://jakearchibald.github.io/svgomg/) — SVG optimizer. Removes unnecessary markup.
- [remove.bg](https://www.remove.bg/) — AI background removal (free tier uploads to cloud; local alternatives exist).
- [Excalidraw](https://excalidraw.com/) — Hand-drawn style diagramming tool. Collaborative, open source.

## Developer Tools

- [JSON-CSV Converter](https://xueboyang1985.github.io/json-csv-converter/) — Format, validate, convert between JSON and CSV. BigInt support.
- [Text Diff Checker](https://xueboyang1985.github.io/text-diff-checker/) — Line/char diff with LCS algorithm. Insertion/deletion highlighting.
- [Base64 Encoder](https://xueboyang1985.github.io/base64-encoder/) — Encode/decode text and files. Hex and binary modes.
- [UUID Generator](https://xueboyang1985.github.io/uuid-generator/) — UUID v4 and v7. Bulk up to 100. crypto.getRandomValues.
- [URL Encoder](https://xueboyang1985.github.io/url-encoder/) — Full URL and component encoding.
- [HTML Formatter](https://xueboyang1985.github.io/html-formatter/) — Tag-aware indentation with preview.
- [CSS Minifier](https://xueboyang1985.github.io/css-minifier/) — Strip whitespace and comments.
- [Timestamp Converter](https://xueboyang1985.github.io/timestamp-converter/) — Unix ↔ human dates. Timezone-aware ISO 8601.
- [Number Base Converter](https://xueboyang1985.github.io/number-base/) — Binary, octal, decimal, hex. Fractions + step-by-step.
- [Transform](https://transform.tools/) — Polyglot web converter. JSON to everything.
- [CyberChef](https://gchq.github.io/CyberChef/) — The Cyber Swiss Army Knife. 300+ operations.
- [JSONLint](https://jsonlint.com/) — JSON validator and formatter.
- [crontab guru](https://crontab.guru/) — Cron schedule expression editor. Visual, instant feedback.
- [JWT.io](https://jwt.io/) — Debug, verify, and decode JSON Web Tokens.
- [BestJSON JSON Diff](https://bestjson.com/json-diff) — Compare JSON structures locally in the browser and inspect added, removed or changed values by path. No account required.
